# OmniCloud website

Static pages for the OmniCloud iOS app, served by GitHub Pages at
https://doubledimple.github.io/omnicloud-site/

- `index.html`: application home page
- `privacy.html`: privacy policy, including the Google API data usage and Limited Use disclosure
- `terms.html`: terms of service

These are the URLs entered on the Google OAuth consent screen. Plain HTML; no build step.
