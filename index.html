OmniCloud

A multi-cloud console for iPhone and iPad. Bring your cloud accounts, Cloudflare services and SSH servers together in one app.

Privacy PolicyHow the app handles your data. ↗ Terms of ServiceThe terms for using OmniCloud. ↗
Local-first by design. OmniCloud has no account system and runs no servers of its own. The app connects directly to your providers and servers. Credentials are protected in your device’s Keychain. Optional iCloud sync keeps supported accounts and SSH connections in your own private iCloud database. See what is stored and synced.

Supported cloud services

Seven cloud providers, plus a dedicated Cloudflare workspace. Tools vary by provider, your permissions and your membership plan.

  • Amazon Web Services

    View EC2 instances and their states across your connected AWS regions.

    Connect: AWS sign-in or access keys.

  • Microsoft Azure

    View virtual machines and their states across the subscriptions you choose.

    Connect: Microsoft sign-in.

  • Google Cloud

    Manage Compute Engine instances, VPC networks and firewall rules. Access Cloud Storage, quotas and audit logs.

    Connect: Google sign-in or a service account key.

  • Oracle Cloud Infrastructure

    Manage compute, networks and volumes, with object storage, billing and account tools.

    Connect: Oracle Cloud sign-in or API keys.

  • Hetzner Cloud

    Create and manage cloud servers, edit network subnets and firewall rules, and view volumes. Browse Hetzner server-auction offers.

    Connect: A Hetzner Cloud API token. Auction orders use separate Robot credentials.

  • netcup

    View servers, their states and details from your Server Control Panel account.

    Connect: netcup device authorization.

  • OVHcloud

    View Public Cloud instances in your connected projects. Browse OVH Eco dedicated-server offers.

    Connect: OVHcloud API credentials. Ordering requires separate authorization.

  • Cloudflare

    A separate workspace for domains and DNS, existing Tunnel routes, R2 browsing and downloads, and Worker information.

    Connect: Cloudflare sign-in to create an API token, or a token you supply.

Tools for your cloud and servers

Use your own accounts and infrastructure. Available actions reflect the capabilities of each connection.

One resource view

Keep connected accounts, instances, regions and states together. Switch workspaces or filter to one provider or account.

Create and manage instances

Oracle Cloud, Hetzner Cloud and Google Cloud support instance creation and management, with provider-specific network and firewall controls. AWS, Azure, netcup and OVHcloud currently support instance viewing.

Cloudflare in its own workspace

Work with DNS records, zone settings and existing Tunnel routes. Browse and download R2 objects and inspect Worker details.

Connect to your servers

Use SSH terminals, SFTP files, port forwarding, process views, system services and Docker tools on servers you provide.

Websites and certificates

Set up Nginx reverse proxies and Let’s Encrypt certificates on your own supported Ubuntu or Debian server, using Cloudflare DNS validation. An existing Nginx installation is accepted only when OmniCloud can verify that it manages it.

Costs and account tools

See cost estimates where available, Oracle billing, and supported quota, storage and audit tools. Estimates are guidance; your provider’s invoice remains authoritative.

Your accounts, your access

You connect accounts you own or are authorized to manage. Provider sign-in opens the provider’s authorization page; supported key-based connections use credentials you supply. OmniCloud does not ask you to create an OmniCloud account.

Google Cloud access continues to follow the Google API Services User Data Policy, including Limited Use. Read the Google permissions and project setup details, how other provider connections work, and how to revoke access.

Server administration and website tasks run on your own servers. Optional iCloud sync uses your own Apple account. See the Privacy Policy for credentials, request logs, sync and data removal.
